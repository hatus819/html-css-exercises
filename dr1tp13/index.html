Como funciona a Web e o que é uma página web

A web é um sistema global de documentos e informacoes ligadas através hiperlinks. Uma pagina web é uma espécie de documento com algumas informacoes podendo elas serem links, imagens, textos, efeitos de transicao por exemplo e até mesmo outros códigos.

Os papéis das linguagens HTML e CSS numa página web

Como falar de uma página web sem citar os seus principais componentes? O que são ambientes de programação?

Esses ambientes onde as vezes os filme apresentam talvez um hacker invadindo um sistema, ou criando códigos incompreensiveis, sao chamados de IDEs. E pra ser sincero nao tem muito segredo. IDE (Integrated Development Environment) ou em PT-BR Ambiente Integrado de Desenvolvimento nos trás uma espécie de caixa de ferramentas para desenvolvermos um sistema. Composto em sua base por um editor de texto, um compilador e um depurador. Mas acredite hoje as IDEs nos trazem muito mais do que isso, como por exemplo auto complete de codigo ou sintaxe, algumas espécies de GPT e prettier (pra deixar seu codigo bonitinho)
